Read and follow `.emw/prompts/02-feature-delivery.md` and `.emw/prompts/07-knowledge-retrieval.md` for the task the developer described in this request.

Inspect the repository, assess L/R/P/N/C/D, select a collaboration mode, and agree on scope, acceptance criteria, learning objective, and verification plan before substantial implementation. Then work in that mode: in Mode 1 the human writes the core logic and you coach and review, so do not implement it for them. Keep delivery and mastery separate. Report checks actually run and knowledge used/captured.
