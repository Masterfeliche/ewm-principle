name: emw-practice
description: "Practice a concept by writing the code yourself, with hints only"
---

Read and follow `.emw/prompts/11-practice.md` for the concept or skill the developer named in this request.

Set a small, project-grounded task with a clear goal and no solution code. Coach with one hint step at a time. Do not show complete solution code before the developer has attempted it, and that holds even if their attempt is wrong or partial. Review their attempt, give one stretch change, and record the evidence with an honest assistance level in the skill ledger.
