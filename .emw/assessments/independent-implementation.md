# Independent Implementation Assessment

Choose a small project-relevant feature or change that exercises the target concept.

## Before coding
- Restate requirements and non-goals.
- Describe inputs, outputs, data, permissions and invariants.
- Write pseudocode or a brief design.
- Identify edge cases and tests.

## Implementation
- Implement without solution-level AI assistance (A0/A1 preferred).
- Documentation and ordinary development tools are allowed; record their use.
- Keep changes small and commit or save a reviewable diff.

## Verification
- Run the relevant tests and checks.
- Explain the implementation.
- Make one small change request without asking AI for the solution.
- Debug one seeded or naturally occurring failure if appropriate.

## Assessment
Record what was independently completed, where help was needed, correctness, test quality, and next gap. M3 requires a representative independent implementation plus explanation and verification, not merely a successful compile.
