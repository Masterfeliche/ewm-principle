# Transfer Assessment

Test whether the developer can apply a concept beyond the exact example previously practiced.

1. Present a related but unfamiliar scenario.
2. Ask the developer to identify what remains the same and what changes.
3. Ask for a design and implementation approach before revealing hints.
4. Require consideration of alternatives and failure modes.
5. Ask the developer to implement or modify a small solution.
6. Ask them to explain limitations and teach the key idea.

Record the unfamiliar element, assistance A0–A4, result, and whether the developer can generalize accurately. M4 requires transfer evidence; repetition of the original exercise is insufficient.
