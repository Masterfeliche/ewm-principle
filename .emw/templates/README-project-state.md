# EMW Project State

These files belong to the consuming software project, not to the shared EMW framework distribution.

Copy this directory to `.emw-project/` during onboarding:
- `project-profile.md`
- `onboarding-status.yaml`
- `delivery-ledger.md`
- `skill-ledger.yaml`
- `task-log.yaml`
- `mode-policy.yaml`

Create `.project-knowledge/` using `.emw/templates/project-knowledge-readme.md` and `.emw/templates/project-knowledge-index.yaml`.

Keep project-specific state outside the shared framework-managed files so framework updates do not overwrite project records. Do not commit secrets or unnecessary personal/customer data.
