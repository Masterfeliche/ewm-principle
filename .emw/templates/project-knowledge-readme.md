# Project Knowledge Base

This directory stores durable, project-specific knowledge for <PROJECT NAME>.

## What belongs here
- Domain and business rules.
- Project architecture and data-model explanations.
- Repository-specific patterns and conventions.
- Integration details and operational runbooks.
- Verified bugs, root causes, fixes, and regression guidance.
- Project-specific security requirements and invariants.
- Rejected approaches and lessons learned.

## What does not belong here
- Credentials, tokens, private keys, or secrets.
- Unnecessary personal or customer data.
- Unverified guesses presented as fact.
- Large copied vendor documentation.
- Generic guidance that belongs in the shared EMW knowledge base.

## Retrieval and contribution
Agents should inspect `index.yaml` and relevant entries before meaningful work. Use the EMW knowledge-entry template and rules. Project knowledge is not automatically shared upstream.
