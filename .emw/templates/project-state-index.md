# Project State Quick Index

This is a suggested index file for `.emw-project/README.md`.

- Project profile: `project-profile.md`
- Onboarding status: `onboarding-status.yaml`
- Engineering delivery ledger: `delivery-ledger.md`
- Developer mastery ledger: `skill-ledger.yaml`
- Learning log: `learning-log.md` (create when useful)
- Task briefs: `tasks/` (create for meaningful work)
- ADRs: project-specific decision-record directory

Project-specific knowledge is stored separately in `.project-knowledge/`.
