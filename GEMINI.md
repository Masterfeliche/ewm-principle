# Gemini CLI Instructions

This repository uses Engineering Mastery Workflow (EMW).

Before meaningful work, read and follow:
1. Root `AGENTS.md`.
2. `.emw/prompts/README.md` and `.emw/prompts/00-session-start.md`.
3. The task-specific prompt selected by the prompt routing table.
4. Relevant policies in `.emw/core/`.

Automatically read and follow the project-onboarding prompt when a consuming project's onboarding records are absent or stale. Retrieve relevant shared and project knowledge before meaningful work. Save durable project lessons; shared knowledge publication requires sanitization and human approval.

Keep delivery and mastery separate. Do not invent tests, results, knowledge evidence, or skill levels.
