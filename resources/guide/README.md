# Visual guide

`emw-workflow-guide.html` is a designed, readable version of [`docs/GUIDE.md`](../../docs/GUIDE.md). Open it in a browser (it needs internet for fonts and the Markdown renderer).

Hosted copy: https://claude.ai/artifact/ND9aXgZEhRQyLc8XhKhtec (private until shared from its Share menu).

After editing `docs/GUIDE.md`, rebuild both files from the repository root:

```bash
python resources/guide/_build/build_guide.py
```

`emw-workflow-guide.artifact.html` is the same page without a doctype, for publishing as an artifact.
