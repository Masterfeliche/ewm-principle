Engineering Mastery Workflow

Use AI to build software, and still be able to build it yourself

How to use the workflow end to end: learning a language from zero, working on a project that already exists, and leading a team. Pick where you are.

Mode: how you work with the AI

1You type; the AI hints
2Plan together; you write the core
3The AI drafts; you audit
4The AI does routine work

Darker means more of the work is yours.

Mastery: what you can do

M0No evidence yet
M1Can explain it
M2Can use it with help
M3Can build and debug it alone
M4Can adapt it and teach it

Assistance: help a piece of work had

A0None beyond documentation
A1A hint or explanation
A2Pseudocode or a pointer
A3The AI wrote part
A4The AI wrote it

The two rules that tie them together. Work done at A3 or A4 never proves M3. And M3 or M4 needs at least one piece of low-help evidence that a person saw.
